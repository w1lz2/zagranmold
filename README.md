# Мониторинг записи в посольство Молдовы (Reservio) → Telegram

Программа каждые ~5 минут берёт все свободные окна по услуге «Изготовление паспорта (загран)»
напрямую из API сайта записи и присылает в Telegram **только новые**:
- окна, освободившиеся после чьей-то отмены;
- новые дни, открывшиеся для записи (запись открыта на 30 дней вперёд).

Работает бесплатно на серверах GitHub — ваш компьютер не нужен.

## Настройка (≈10 минут)

### 1. Telegram-бот
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен** (вида `123456:ABC...`).
2. Найдите своего бота и нажмите **Start** (иначе он не сможет вам писать).
3. Откройте **@userinfobot** → он пришлёт ваш **Id** (число).

### 2. Репозиторий на GitHub
1. Зарегистрируйтесь на github.com → **New repository** → любое имя, тип **Public** → Create.
   (Public — чтобы запуски каждые 5 минут были бесплатными. Токен в код не попадает — он в секретах.)
2. **Add file → Upload files** → перетащите `monitor.py`, `requirements.txt`, `README.md` → Commit changes.
3. **Add file → Create new file** → в поле имени напишите ровно
   `.github/workflows/monitor.yml` → вставьте содержимое файла `monitor.yml` → Commit changes.

### 3. Секреты
**Settings → Secrets and variables → Actions → New repository secret**:
- `TG_TOKEN` — токен бота
- `TG_CHAT_ID` — ваш Id

### 4. Запуск
**Actions** → (если попросит — включите workflows) → **Мониторинг записи** → **Run workflow**.
Через минуту в Telegram придёт «✅ Мониторинг запущен» со сводкой свободных сейчас окон.
Дальше всё работает само.

## Пример уведомления
```
🟢 Новые свободные окна (33) — Изготовление паспорта (загран)

👤 Владимир Руснак
  вт 17.11: 10:15
👤 Дойна Гайтур
  пт 27.11 🆕 новый день: 32 окна (08:00–15:45)
```

## Дополнительно
- **Только определённые сотрудники:** Settings → Secrets and variables → Actions → вкладка **Variables** →
  `STAFF` = `Владимир Руснак, Дойна Гайтур` (по умолчанию — все, кто ведёт услугу).
- **Другая услуга:** переменная `SERVICE_ID`. Список ID услуг печатается в логе первого запуска
  (Actions → запуск → «Проверка свободных окон»).
- После 3 ошибок подряд бот пришлёт предупреждение.

## Ограничения GitHub
- «Каждые 5 минут» — минимум; в часы нагрузки GitHub может запускать реже (раз в 10–15 минут).
- Если в репозитории 60 дней нет изменений, GitHub приостанавливает расписание (пришлёт письмо,
  включается одной кнопкой). Программа сохраняет `state.json` при каждом изменении окон, поэтому
  при живой записи это почти не случается.

## Вариант: свой сервер (VPS) — проверка раз в 2 минуты
```bash
pip install requests
export TG_TOKEN=... TG_CHAT_ID=... INTERVAL_MIN=2
nohup python3 monitor.py --loop > monitor.log 2>&1 &
```
